**LIONIKS**

Chemical Element Family Classifier

LIONIKS is a Machine Learning project designed to identify the chemical family of an element based on its physical and chemical properties.

Using a trained classification model, LIONIKS analyzes information about a chemical element and predicts which family it belongs to, helping users explore and understand the organization of the Periodic Table.

🔬 **Project Overview**

The Periodic Table organizes chemical elements into families according to their properties and electron configurations.

LIONIKS aims to automate this classification process using Machine Learning techniques.

The project uses a supervised learning approach, where a model is trained on a dataset containing chemical elements and their respective properties.

After training, the model can analyze new element data and predict its corresponding chemical family.

⚛️ **Supported Element Families**

The classifier is designed to recognize the following chemical families:

Alkali Metals

Alkaline Earth Metals

Transition Metals

Lanthanides

Actinides

Boron Group

Carbon Group

Pnictogens

Chalcogens

Halogens

Noble Gases

Nonmetals

🤖 **Machine Learning**

LIONIKS uses a classification model trained on chemical element data.

The model analyzes element characteristics to identify patterns associated with different chemical families.

Main Machine Learning tasks:

Data preprocessing and cleaning.

Feature selection and engineering.

Model training.

Multi-class classification.

Model evaluation using classification metrics.

Evaluation metrics include:

Accuracy

Precision

Recall

F1-score

🌐 **Web Application**

LIONIKS also includes a web interface developed with Streamlit, allowing users to interact with the trained Machine Learning model.

Users can provide the characteristics of a chemical element and receive a predicted classification.

Main Features

Interactive element classification.

Machine Learning-powered predictions.

Chemical family identification.

User-friendly interface.
